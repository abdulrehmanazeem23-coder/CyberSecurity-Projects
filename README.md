## 🚀 Projects Overview

### 1. [Secure-File-Vault](./Secure-File-Vault)
A cryptographic file vault application designed to secure sensitive documents through authenticated access and symmetric encryption.
- **Key Highlights**:
  - Symmetric key generation and file-level encryption using Fernet / AES-256.
  - Multi-user authentication, registration, and session isolation.
  - Comprehensive activity logging for security compliance and audit trails.
- **Documentation**: Refer to the [`Secure-File-Vault`](./Secure-File-Vault) folder for source code and setup instructions.

---

### 2. [Live-Location-Tracker](./Live-Location-Tracker)
An educational demonstration platform simulating modern social engineering reconnaissance vectors utilizing browser-based Geolocation APIs.
- **Key Highlights**:
  - Interactive weather forecast bait interface requesting device geolocation.
  - Sub-second real-time coordinate streaming using Socket.io WebSockets.
  - Live target tracking visualization on an OpenStreetMap Leaflet dashboard.
  - Instant public accessibility via integrated Cloudflare quick tunneling (`cloudflared`).
- **Documentation**: See [`Live-Location-Tracker/README.md`](./Live-Location-Tracker/README.md) for full architecture and installation steps.
